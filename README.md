## AEO / GEO

The site is built to be read by answer engines as well as people:

- `llms.txt` opens with a **Quick Answers** block covering the questions most often asked
- `robots.txt` explicitly allows the current AI crawlers (GPTBot, OAI-SearchBot, ClaudeBot, Google-Extended, PerplexityBot, Applebot-Extended and others)
- **FAQPage** JSON-LD on the homepage, alongside ProfilePage / Person / SoftwareApplication
- `data/manifest.json` declares a **disclosure boundary** telling agents which figures are published and instructing them not to infer the rest
