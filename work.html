How I evaluate

  • Golden sets built per use case, mapped question by question to the query that answers it
  • Metrics that matter for that use case—a reporting answer and a menu edit do not fail the same way
  • Hallucination as a standalone gate: zero tolerance on anything financial
  • Regression run as the release decision, not a sign-off collected afterwards

The bar I set for voice

  • ≤500ms p50 voice-to-screen
  • ≤800ms p95 voice-to-screen
  • ≥90% speaker attribution under overlapping speech
  • ≤0.05 calibration error, so stated confidence means something
  • ≤1.5× word-error ratio across accent subgroups
  • ≥20dB signal-to-noise at conversational room volume
  • 5-phase ramp from lab to live, each with its own exit gate
